# Project Initiation Document (PID) Template

**Primary Roles:** Project Sponsor, Project Manager, Senior Supplier, Steering Group  
**Phase:** Design Gate (Pre-Submission)  
**Purpose:** Comprehensive project plan and "contract" between Project Manager and Steering Group for project execution

**Note:** The PID is a "living document" that evolves throughout the project and is reviewed after each major phase. The approved PID version becomes the basis for project evaluation at closure.
