# Portfolio Management Execution Templates & Checklists

*Role-Aware Templates aligned with Didier's Portfolio Governance Model*

Each template previously lived as a section in this file. They're now split
into standalone files (one per template, named after the template itself)
so each can be read, edited, or referenced independently — see
`docs/decisions/DECISION-LOG.md` for why this file stays as an index rather
than being deleted.

---

## Primary Templates

| # | Template | Primary Roles | Phase |
|---|---|---|---|
| 1 | [Project Idea Submission Template](Project%20Idea%20Submission%20Template.md) | Project Sponsor, Business Owner, Portfolio Manager | Idea Gate (Pre-Submission) |
| 2 | [Project Brief Template](Project%20Brief%20Template.md) | Project Sponsor, Business Owner, Senior User, Portfolio Manager | Definition Gate (Pre-Submission) |
| 3 | [Project Initiation Document (PID) Template](Project%20Initiation%20Document%20%28PID%29%20Template.md) | Project Sponsor, Project Manager, Senior Supplier, Steering Group | Design Gate (Pre-Submission) |
